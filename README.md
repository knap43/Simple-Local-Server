# Simple-Local-Server
A home server with video and audio players, image viewer and text editor included. Controller support and mobile friendly.

Disclaimer: the code in its entirety was written by an LLM, use by your own discretion.

### How to use:
1. Clone the repo and cd into the folder
2. Install the dependencies (on Arch: sudo pacman -S python-flask python-pillow)
3. Run it (python3 server-remote.py /path/to/root)
4. You can now access it from any device on the same network
