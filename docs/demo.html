Controls

Keyboard

↑ ↓ ← →Move between files and folders
EnterOpen the highlighted item
BackspaceUp one folder / close a dialog
/Jump to search
G / LGrid view / list view
SpacePlay / pause (in video/audio player)
← →Seek 5s (in video/audio player) / prev-next image
FToggle fullscreen (in video player)
LPlay next (in video/audio player)
EscClose a dialog

Gamepad — browsing

D-pad / StickMove between files and folders
AOpen / activate
BUp one folder / close a dialog
XToggle grid / list view
YJump to search
L1 / R1Change sort field
SelectReverse sort order
StartShow / hide this panel

Gamepad — video / audio player

D-pad ← →Seek 5 seconds back / forward
D-pad ↑Toggle fullscreen (video only)
APlay / pause
BClose the player
everything elseIgnored while playing

Gamepad — image viewer

D-pad ← →Previous / next image
BClose the viewer
everything elseIgnored while viewing

Resuming a video

D-pad / ← →Choose Resume or Start over
A / EnterConfirm the highlighted choice
